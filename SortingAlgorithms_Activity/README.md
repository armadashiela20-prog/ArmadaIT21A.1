Sorting Algorithms in Java

Program Description

Kini nga Java program nagpakita kung giunsa paghan-ay ang mga number gamit ang tulo ka sorting algorithms:
Ang Bubble Sort, Selection Sort, og Insertion Sort.

    kani nga program kay naggamit og array nga naay napulo ka wala pa mahan-ay nga mga number ,Ang matag sorting algorithm adunay kaugalingong method ug naggamit og
    separate copy sa original array.,Ang resulta ipakita sa ascending order, gikan sa pinakagamay hangtod sa pinakadako nga numero.

1. Bubble Sort
    Ang Bubble Sort kay gina kumpara niya ang duha ka magtapad nga number.
Kung ang unang number mas dako kaysa ikaduha, ilang ibaylo ang ilang position, Balik-balikon balik balikon dayon hangtod mahan-ay ang tanan nga number.

2. Selection Sort
    Ang Selection Sort mangita sa pinakagamay nga number sa array.pagmakita na dayon kay ibutang siya sa unang position,
Dayon mangita na pud sa sunod nga pinakagamay nga numero hangtod mahuman ang paghan-ay.

3. Insertion Sort
    Ang Insertion Sort parehas sa paghan-ay og playing cards.
Magkuha kini og usa ka number ug ibutang sa sakto nga position pananglitan ang 1,5,7,2,4,3 kwaon ang 2 eh drag dayon siya padulong sa 1 eh abay sila duha balik balik ra 
 kung asa siya taliwala sa mga number nga nahuman na og han-ay.

Differences Between the Three Algorithms

Lahe-lahe ang proseso sa tulo ka sorting algorithms.

Bubble Sort: Nagkumpara sa magtapad nga mga number ug magbaylo sa ilang position.
Selection Sort: Mangita sa pinakagamay nga number ug ibutang kini sa sakto nga position.
Insertion Sort: Magkuha og usa ka number ug isulod or ibutang kini sa hustong lugar.

Reflection Questions and Answers

1. How does each sorting algorithm arrange numbers? What makes their processes different?
   Ang Bubble Sort magkumpara sa duha ka tapad nga number. Ang Selection Sort mangita sa pinakagamay nga number ug ibutang sa unahan.
Ang Insertion Sort magkuha og number ug ibutang kini sa sakto nga lugar,Pareho silang naghan-ay og numero pero lahi ang ilang pamaagi.

2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?
   Para nako, ang Bubble Sort ang pinakasayon sabton ug buhaton kay magkumpara ra kini sa duha ka tapad nga numero.
Sayon ra sundon ang proseso kay kung sayop ang order, ibaylo lang ang ilang position dali rapud siya mahuman.

3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.
   Para nako, ang Bubble Sort mahimong mas paspas kung daan nang sorted ang mga number.
Tungod kay kung walay kinahanglan ibaylo nga numero sa usa ka round, mohunong na ang program ug dili na ipadayon ang uban nga rounds.

4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?
   Kung modaghan ang mga number sa array, mas daghan na pud ang kinahanglan susihon ug han-ayon.
Mahimong mas dugay ang tulo ka algorithms, labi na kung daghan kaayo ang mga number,Ang ilang performance nakadepende sa kadaghan ug kahimtang sa mga number.

5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?
   Importante nga makat-on ta og lain-laing sorting algorithms kay dili tanan parehas og performance.
Isip future programmer, kinahanglan makahibalo ta mopili sa angay nga algorithm depende sa kadaghan sa data ug sa sitwasyon sa atong program para makita dayon ang
resulta pag nakapili na kung unsa na algorithm og dili na maglibog og pag han-ay.
